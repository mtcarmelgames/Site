Use Replace for each placement group and upload the corresponding PNG. Match the aspect-ratio radio option to that file and check the actual Facebook/Instagram previews. Leave AI expansion and generated text/image alterations off for the first controlled test. The vertical creative reserves space at the top and bottom, but exact overlays vary by placement.
